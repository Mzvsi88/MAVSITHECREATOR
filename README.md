# Mavsi | The Creator — Free Website

This is a free, static website for Mavsi / Emmanuel Chigozirim.

## Put it online for free
1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new repository. A simple name such as `mavsi-website` works.
3. Upload `index.html`, `styles.css`, this README, and the `media` folder.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main`, and save.
6. GitHub will give you a free `github.io` website address.

## Add your videos
Put your MP4 files in `media/`, then replace the three placeholder cards in `index.html` with `<video>` elements. Keep videos compressed for free hosting.
